# Dashboard Mockup Notes

The static preview in `preview/` represents the intended Qlik Sense layout style:

- compact header with sheet navigation
- filter pane directly under the header
- KPI strip for executive metrics
- station ranking, monthly trend, and risk table
- operational wording that supports management action

The mockup intentionally avoids a marketing landing-page style. It is meant to resemble an internal reporting surface used during weekly station performance reviews.
